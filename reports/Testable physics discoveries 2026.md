# Mentat Reproduces 2026's Basics, Misses Its Frontier

From 10 June to 10 October 2026, physics mostly consolidated rather than overturned, and sigma-ground's engine can confirm that consolidation only where it has closed-form code. We ran 41 hooks from the new literature through Mentat. It reproduces every textbook quantity it implements, usually to better than 0.1%: the Hubble radius, the critical density, ΛCDM ages, Schwarzschild black-hole thermodynamics, neutron-star compactness, the recoil kinematics of the LZ event, and the energy of the ²²⁹Th clock photon. The window's biggest results fall into gaps. DESI's evolving-dark-energy fit (now 2.7–3.5σ), GW250114's Kerr ringdown and area growth, NICER's compact 1.94 M☉ pulsar and the neutron-star maximum mass, and the σ-sensitivity of the first working nuclear clocks all need modules the engine lacks: H(z), Kerr spin, a TOV solver and a nuclear-clock model. Where the engine contradicts the data, the cause is either stale constants or the speculative σ framework. On the constants side, it reports a 5.2σ muon g−2 anomaly that the 2025 inputs reduce to 0.6σ. On the σ side, its holographic dark-energy identification falls 40% short of the observed density, and its r_s = R_H identity holds for every H₀, so it tests nothing. The August 2026 China Space Station equivalence-principle test also excludes a long-range σ at ξ = 0.158 by a factor of 16, in addition to MICROSCOPE's factor of 10¹¹. We flagged thirteen suspected bugs for review and fixed none. The Mentat MCP server could not connect from this cloud session, so every check ran on a locally launched copy.

## Forty-one checks split cleanly into passing closed forms and missing modules

### How the checks ran when the MCP server would not connect

`.mcp.json` starts the Mentat server with `docker exec -i skippytel-mentat python -m sigma_ground.mcp.server`. That command runs inside the SkippyTel container on the user's own machine, which a cloud container cannot reach, so this session reported the server as CONNECTION_CLOSED. Launching Mentat locally exposed two more deployment faults. First, **the installed mcp 2.x package renamed the FastMCP class** that `sigma_ground/mcp/server.py:78` imports from `mcp.server.fastmcp`, and `pyproject.toml:63` declares `mcp>=1.0` with no upper bound, so a fresh install pulls in the incompatible version. Second, `lookup_constant`, `convert_units` and every symbolic tool failed with "No module named 'periodictable'" until scipy, sympy, pint and periodictable were installed. The checks therefore ran on a locally launched Mentat (232 tools over stdio), with mcp<2 and those four libraries installed into a scratch directory. No repository file was modified ([engine checks](../research_notes/Testable%20physics%20discoveries%202026/mentat_engine_checks.md)).

No MCP tool exposes σ ≠ 0 physics, an H₀ argument or the muon g−2, so some rows called the engine's Python functions directly. Rows that needed a non-Planck cosmology set H₀ and Ω_m in memory before calling the engine's own formulas. Rows that only evaluated a textbook formula through Mentat's sympy calculator count as engine gaps. Two systematic offsets apply throughout. The engine's megaparsec is 3.086×10²² m (`sigma_ground/field/constants.py:414`), which puts ρ_c 0.02% low and R_H and ages 0.01% high. Its solar mass is 1.989×10³⁰ kg, 0.03% above the IAU-consistent 1.98841×10³⁰ kg. A hook **REPRODUCES** if it agrees within the reference uncertainty, or within 1% for derived quantities. It **CONTRADICTS** if it disagrees, is an **ENGINE GAP** if no code path can compute it, and is a **SUSPECTED BUG** if the engine's own behaviour looks wrong.

## Cosmic expansion data drifted toward ΛCDM while Mentat stayed pinned to Planck 2018

The window's main dark-energy release came from DESI's DR2 Lyman-α full-shape Alcock–Paczyński analysis (collaboration preprint, 29 July). It measured **D_H/r_d = 8.600 ± 0.066 and D_M/r_d = 39.32 ± 0.33 at z = 2.33** and found Ω_m = 0.325 ± 0.018, 1.4σ above the DESI BAO value and closer to Planck ([arXiv:2607.27410](https://arxiv.org/abs/2607.27410)). That shift softened the evolving-dark-energy preference: DESI+CMB fell from 3.1σ to 2.7σ, while supernova combinations gave **w₀ = −0.821 ± 0.054, w_a = −0.65 ± 0.20 at 3.2σ** with DES-Dovekie, 3.0σ with Pantheon+ and 3.5σ with Union3.1 ([arXiv HTML](https://arxiv.org/html/2607.27410)). DESI itself wrote that the hints "may fade away, or alternatively, that a more complex model may be needed" ([DESI news](https://www.desi.lbl.gov/2026/07/30/new-desi-dr2-lyman-alpha-results-shed-light-on-dark-energy/)). Every recalibration has moved in the same direction. The peer-reviewed DES-Dovekie supernova reanalysis (background, April 2026) cut the DESI+CMB+SN significance from 4.2σ to 3.2σ ([MNRAS](https://academic.oup.com/mnras/article/548/4/stag632/8653925)). Two peer-reviewed reanalyses inside the window went further. Lozano Torres found 3σ in Δχ² but inconclusive Bayesian evidence (ln B ≈ −0.5) ([MNRAS](https://academic.oup.com/mnras/advance-article/doi/10.1093/mnras/stag1607/8771483)), and Kandel et al. found the preference **below 1σ for most parametrizations** with a compressed CMB likelihood ([EPJC](https://link.springer.com/article/10.1140/epjc/s10052-026-16010-6)). SPT-3G's quadratic-estimator lensing (collaboration preprint, 31 August) cut the w₀w_a preference to about 2σ and set **Σm_ν < 0.072 eV** ([arXiv:2608.31136](https://arxiv.org/abs/2608.31136)). An ACT DR6 + DESI DR2 preprint pushed the neutrino-mass limit to Σm_ν < 0.052 eV, below the 0.059 eV normal-ordering minimum ([arXiv:2606.17994](https://arxiv.org/abs/2606.17994)). DESI's DR3 BAO and five-year dark-energy results are due in 2027, not in this window.

The S₈ tension is fading while the H₀ tension is not. KiDS-Legacy's joint second- and third-order shear (preprint, June) found **S₈ = 0.806 (+0.025/−0.023) with "no evidence for an S₈ tension"** ([arXiv:2606.12389](https://arxiv.org/html/2606.12389)). DES Y6 remains the low holdout at 0.789 ± 0.012 (background) ([arXiv:2601.14559](https://arxiv.org/abs/2601.14559)). On H₀, the peer-reviewed H0DN consensus value of **73.50 ± 0.81** (background, April 2026) sits 7.1σ from the CMB-SPA ΛCDM value of 67.24 ± 0.35 and 5.0σ from DESI+BBN ([A&A](https://www.aanda.org/articles/aa/abs/2026/04/aa57993-25/aa57993-25.html)). In-window work did not arbitrate. A June review calls the tension "likely … a real crisis" ([arXiv:2606.20434](https://arxiv.org/abs/2606.20434)), and the best dark-siren combination, 69.9 (+4.2/−4.0), is too broad to pick a side ([JCAP](https://iopscience.iop.org/article/10.1088/1475-7516/2026/08/068)).

Whether the universe is still accelerating became a live, two-group dispute in peer-reviewed journals. Sah, Rameez & Sarkar argued that Pantheon+ corrected for progenitor age implies deceleration ([MNRAS](https://academic.oup.com/mnras/article/549/3/stag844/8701424)). Wiseman, Popovic, Sullivan, Riess and Scolnic countered in the same MNRAS volume that SN cosmology is "robust to host galaxy age evolution" ([MNRAS](https://academic.oup.com/mnras/article/549/3/stag797/8703725)). An August preprint found q_m = −0.490 without the age correction and −0.267 with it, still accelerating either way ([arXiv:2607.20570](https://arxiv.org/html/2607.20570)). A preprint on ~147,000 old Galactic stars put the oldest at **13.80 (+0.20/−0.16) ± 0.4 Gyr** and concluded that a high-H₀ ΛCDM universe, about 12.7 Gyr old, conflicts with them ([arXiv:2607.00764](https://arxiv.science/abs/2607.00764)). Holographic dark energy, the class closest to sigma-ground's own η premise, was fitted to DESI DR2 repeatedly. An in-window preprint found that **Hubble-horizon and particle-horizon cut-offs are strongly ruled out once CMB distance priors are added**, with only the future-event-horizon cut-off tracking ΛCDM ([arXiv:2608.09379](https://arxiv.org/abs/2608.09379)). A background paper declares the original HDE and Ricci variants "ruled out" ([arXiv:2509.02945](https://arxiv.org/abs/2509.02945)). An October preprint finds the Barrow area-law deformation compatible with zero ([arXiv:2610.11616](https://arxiv.org/abs/2610.11616)).

Mentat reproduced every ΛCDM regression target in this section, but only after its constants were overridden in memory. The MCP tools `hubble_radius`, `critical_density` and `age_of_universe` (`sigma_ground/mcp/tools/cosmology.py:16-31`, `:141-156`, `:164-213`) take no H₀ or Ω_m argument and always use Planck 2018 (H₀ = 67.4, Ω_m = 0.315). **Mentat therefore silently takes one side of a 7σ dispute.** With overrides, c/H₀ came out at 4458.54 Mpc (H₀ = 67.24) and 4078.81 Mpc (73.50), ρ_c within 0.02%, and the DESI+CMB age at 13.795 Gyr against a reference of 13.79. Run at H0DN's 73.50, the engine's own ΛCDM gives **t₀ = 12.653 Gyr, about 0.65 Gyr below the 13.3 Gyr oldest-star floor**, so it reproduces the age tension the literature describes. The engine cannot reach the DESI headline. It has no H(z), D_M, D_H, r_d, w₀ or w_a anywhere, so the z = 2.33 distances cannot be computed. For the DESI+CMB+Dovekie w₀w_a fit, the ΛCDM-only code returns t₀ = 13.824 Gyr against 13.75, and the deceleration parameter is about −0.53 against the w₀w_a value of −0.345 (CALC). The holographic test is the sharpest contradiction. `hde_rho_de` (`sigma_ground/field/interface/cosmology.py:196`) with c² = η = 0.4122 and L = R_H gives 3.16×10⁻¹⁰ J/m³, against Ω_Λρ_c c² = 5.25×10⁻¹⁰. That ratio is **0.6017 (0.5911 with DESI+CMB parameters)**, which reproduces the repo's own documented deficit and contradicts the observed dark-energy density by about 40%. Inverting through `holographic_dark_energy_analysis` always returns c² ≡ Ω_Λ (0.6847). That is the trivially satisfied Hubble-cutoff class the 2026 fits exclude. The one surviving cut-off, the future event horizon, needs H(z). The DR3 check `eta_desi_band_check('dr3')` returns `in_band: false` with "DR3 numerics not yet lifted". No DR3 HDE result exists, so the unpublished prediction UP-001 cannot be tested until 2027. The stored Σm_ν bound of 0.072 eV (`constants.py:83`) matches only the SPT-3G combination and is 12–22% looser than DESI DR2. The oscillation splittings (`constants.py:75-77`, PDG 2022) still agree with JUNO 2026 within 0.4σ.

## Black holes passed every Kerr test the engine cannot yet run

The LIGO–Virgo–KAGRA catalogs are now public through O4b. GWTC-4.0 was formally published in ApJL on 18 June ([IOPscience](https://iopscience.iop.org/article/10.3847/2041-8213/ae2c74)). GWTC-5.0, released on 26 May just before the window, brought the cumulative total to 390 candidates ([arXiv:2605.27225](https://arxiv.org/abs/2605.27225)). The GWTC-5.0 tests-of-GR paper (collaboration preprint, 21 July) analysed 168 events and found **"no evidence for physics beyond GR"** ([arXiv:2607.19293](https://arxiv.org/abs/2607.19293)). The loudest event, GW250114, was established in a peer-reviewed 2025 PRL (background): a remnant of 62.7 M☉ with spin 0.68, and the Hawking area law confirmed at 4.4σ ([PRL via NSF PAR](https://par.nsf.gov/servlets/purl/10650616)). In-window preprints pushed its ringdown further. An independent RingCWB analysis found **f₂₂₀ = 249.0 (+5.4/−5.7) Hz, τ₂₂₀ = 4.1 (+0.4/−0.3) ms and δf₂₂₀ = 0.004 (+0.022/−0.023)**, i.e. Kerr to about 2% ([arXiv:2610.09503](https://arxiv.org/html/2610.09503)). Quadratic quasinormal modes appeared at 3.4σ ([arXiv:2601.05734v2](https://arxiv.org/html/2601.05734v2)), with a coupling coefficient within 1.3σ of GR ([arXiv:2609.28953](https://arxiv.org/html/2609.28953)). The 236 M☉ GW231123 may be eccentric, with e = 0.34 and a Bayes factor of 10.2 ([arXiv:2610.12205](https://arxiv.org/html/2610.12205)). The final O4 catalog is due in December 2026, and O5 is expected "some time in 2029" ([Nature Astronomy](https://www.nature.com/articles/s41550-026-02940-4)). NANOGrav's chromatic-noise reanalysis (collaboration preprint) lowered the nanohertz background to **A = 2.1 (+0.6/−0.5)×10⁻¹⁵** at 3.32σ, moving it toward the supermassive-binary expectation ([arXiv:2606.28554](https://arxiv.org/html/2606.28554)). No EHT collaboration paper appeared in the window.

Compact-star and early-universe results tightened the collapse thresholds any "bond-failure" ladder would have to hit. NICER's first radius for the heavy pulsar PSR J1614−2230 (preprint, 31 August) is **R = 10.06 (+1.25/−0.87) km at 1.937 M☉**, the most compact NICER star so far ([arXiv:2609.00172](https://arxiv.org/abs/2609.00172)). Folded into χEFT+pQCD inference, it pulls heavy-star radii down by about 0.4 km ([arXiv:2609.00173](https://arxiv.org/abs/2609.00173)). A peer-reviewed six-year J0030+0451 reanalysis removed the old 14.4 km solution in favour of 12.68 km ([arXiv:2602.23743](https://arxiv.org/abs/2602.23743)). The maximum neutron-star mass stays above 2.27 M☉ at 1σ (background) ([ApJ](https://iopscience.iop.org/article/10.3847/1538-4357/ae28c5)). JWST's "little red dots" consolidated as black-hole stars wrapped in dense photospheres ([ApJ, Kokorev et al.](https://iopscience.iop.org/article/10.3847/1538-4357/ae4ed7)), but their masses disagree by about two orders of magnitude. Atmosphere fits give 10⁴–10⁵ M☉ ([arXiv:2609.09274](https://arxiv.org/abs/2609.09274)), while QSO1's dynamical mass is about 5×10⁷ M☉ ([Nature](https://www.nature.com/articles/s41586-026-10579-4), published 27 May, just before the window). A September Nature simulation forms ~10⁶ M☉ heavy seeds naturally in irradiated protoclusters ([Nature](https://www.nature.com/articles/s41586-026-10985-8)). In-window theory preprints argue that de Sitter-core regular black holes cannot be built from non-negative sectors ([arXiv:2609.13704](https://arxiv.org/abs/2609.13704)), which sets an energy-condition cost for any nonsingular or "cavitation" interior.

Mentat handled every Schwarzschild quantity correctly and every spin-dependent quantity not at all. For GW250114's remnant it returned **r_s = 185.22 km and T_H = 9.838×10⁻¹⁰ K**, and E_rad = 5.542×10⁴⁷ J, i.e. 4.71% of the initial mass, matching the measured 3.1 M☉c². The area theorem passes qualitatively (the area grows), but without spin the engine gets **A_f/A_i = 1.815 against the Kerr value of 1.57, 15.6% too high**. The Kerr T_H and area would both be about 0.85× the Schwarzschild values. A grep for kerr, quasinormal and qnm finds nothing in the physics code, so the ringdown frequency is an outright gap. For J1614−2230, `schwarzschild_radius` and `gravitational_redshift` give **GM/Rc² = 0.2844 and surface redshift 0.5229**, and the 2.35 M☉/12 km case gives 0.2893, both matching the literature to under 0.2%. J1614 therefore sits at 64% of the Buchdahl limit. The engine has no Buchdahl, TOV, equation-of-state, Chandrasekhar or polytrope code (`sigma_ground/field/interface/test_unsolved_frontiers.py` cites a "TOV solver" that does not exist), so M_TOV and NICER radii cannot be predicted. The thermodynamic identities came out exact. At the Hubble mass, `hawking_temperature` gives 1.32754×10⁻³⁰ K and the de Sitter temperature is 2.65508×10⁻³⁰ K, **a ratio of 0.50000 at every H₀ tested**. The Bekenstein–Hawking entropy at R_H is 2.26591×10¹²² k_B, matched exactly by the `entanglements_to_pop_bubble` thread count. The advertised full-cascade tool `procedure_black_hole_profile` failed on every call (bug B1 below).

## Dark matter, particle and fluid results exercise the engine's kinematics, not its models

### Dark-matter hints stayed hints: one LZ event, a 20 GeV halo and a 3.5 keV residual

The window's direct-detection headline is a single LZ nuclear-recoil-like event at **248 ± 23 ± 23 keV, with 3.4σ local and 2.6σ global significance** in a 2.84 t·yr exposure ([arXiv:2609.02823](https://arxiv.org/abs/2609.02823); [Berkeley Lab](https://newscenter.lbl.gov/2026/09/01/lz-sees-surprising-result-in-search-for-dark-matter/)). It is a collaboration preprint from a non-blind analysis whose S1 pulse shape cannot conclusively separate electron from nuclear recoils ([alphaXiv](https://www.alphaxiv.org/abs/2609.02823)). More than 25 theory preprints followed. Several fit a ~1.1 TeV higgsino with a 300–500 keV mass splitting ([arXiv:2609.04175](https://arxiv.org/abs/2609.04175)), but none is refereed, and XENONnT's cross-check is still pending. Indirect hints also strengthened without converging. A peer-reviewed dwarf-galaxy reanalysis reached **3.7σ local and 3.0σ global** at 100–200 GeV (bb̄) ([ApJL](https://beta.iopscience.iop.org/article/10.3847/2041-8213/ae71c7)). A preprint confirmed the Fermi "20 GeV halo" at the pixel level with best fits of 0.55–0.72 TeV, about five times above dwarf limits ([arXiv:2607.08552](https://arxiv.org/html/2607.08552)). An XRISM Milky-Way-halo preprint found a **3.5311 keV residual at 2.0–2.5σ global** ([arXiv:2610.01877](https://arxiv.org/html/2610.01877v1)). On small scales, a June preprint on 28 JWST lenses confirmed CDM down to 10^7.2 M☉ ([arXiv:2606.05277](https://arxiv.org/abs/2606.05277)). A September preprint on 29 quads instead favoured core-collapsed SIDM halos by Bayes factors of 6–24 ([arXiv:2609.35974](https://arxiv.org/html/2609.35974)). The wide-binary MOND test remains split. Chae & Yoon claim a >5σ anomaly (preprint) ([arXiv:2607.14450](https://arxiv.org/abs/2607.14450)), against a background analysis finding Newton up to 1500× more likely ([arXiv:2602.24035](https://arxiv.science/abs/2602.24035)). The peer-reviewed MUSE-DARK III result (background, May) shows the acceleration scale rising with redshift, a₀(z) = (1.0 + 1.59z)×10⁻¹⁰ m/s² ([A&A](https://www.aanda.org/articles/aa/full_html/2026/05/aa59230-26/aa59230-26.html)). An MNRAS refit gives a₀ ∝ (1+z)^0.78±0.15, consistent with tracking H(z) ([MNRAS](https://academic.oup.com/mnras/article-pdf/551/4/stag1485/70983473/stag1485.pdf)). A peer-reviewed haloscope paper excluded a candidate axion signal at 1.036 GHz ([PRL](https://journals.aps.org/prl/abstract/10.1103/2sn2-h97m)). Two September preprints found the DESI-era preference for dark-matter–dark-energy coupling largely degenerate with w₀w_a ([arXiv:2609.03062](https://arxiv.org/abs/2609.03062)).

Mentat can check the kinematics of these hints but not their rates or models. Converting the ¹³¹Xe mass and the recoil energy through `convert_units`, `kinetic_energy` and `momentum` gave **q = 245.93 MeV/c**, against the literature's 246 MeV ([arXiv:2609.14799](https://arxiv.org/abs/2609.14799)). Feeding `collision_analysis` a head-on 74 GeV particle at 800 km/s gave E_R,max = 247.7 keV, so elastic scattering needs m_χ ≳ 74 GeV at that velocity, consistent with the paper's ≳79 GeV under a different v_max. `photon_energy_from_frequency` maps 1.036 GHz to 4.285 μeV. `mond_a0_constant` stores 1.2×10⁻¹⁰ m/s². ## The σ-field premises fail every test the 2026 data can reach

Most of the speculative machinery is no longer in this repository, so the engine can test only its remnants. The live `sigma_ground.field` package describes itself as standard and observation-anchored, with σ an inert hook (e^σ = 1 at σ = 0). The constants file records that ξ and σ_conv were "relocated to ssbm-theory" (`sigma_ground/field/constants.py:26,158`). ξ = 0.1582 survives only in `sigma_ground/inventory/core/sigma.py:39`. No Python file implements space cavitation or the eight bond-failure layers. The black-hole-merger modules named in `misc/` documents (`bh_merger.py`, `imr_consistency.py`, `bh_mass_function.py`, `sgr_a_star_rate.py`) are absent from the tree ([capability map](../research_notes/Testable%20physics%20discoveries%202026/sigma_ground_capabilities.md)). The project's own instructions describe the separate ssbm-theory repo as "unverified SSBM black-hole-merger research … currently broken in isolation" ([CLAUDE.md](../CLAUDE.md)). The repo's own recorded verdicts already cut against the merger hypotheses: a 15.8% merger mass loss was "falsified at ≥6σ" by GWTC-3 inspiral–merger–ringdown consistency ([bh_imr_verdict](../misc/bh_imr_verdict.md)). The 2026 ringdown results add a further constraint: whatever lies inside a horizon, its exterior must stay Kerr to |δf₂₂₀| ≲ 0.02–0.03 ([arXiv:2610.09503](https://arxiv.org/html/2610.09503)).

**The r_s = R_H identity is a tautology of flat FLRW cosmology, not a discovery.** For the critical density ρ_c = 3H²/8πG, the mass inside a Hubble sphere is M = ρ_c(4π/3)(c/H)³ = c³/(2GH), and its Schwarzschild radius is exactly c/H for any H. Mentat confirmed this directly. `schwarzschild_radius` applied to `M_HUBBLE_KG` (`sigma_ground/field/constants.py:421`) returns 1.372640×10²⁶ m, identical to `hubble_radius`, and **r_s/R_H = 1.000 at every H₀ tested**, from 4.65×10²² M☉ at H₀ = 67.4 to 4.26×10²² M☉ at 73.50. An identity that holds for every cosmology cannot distinguish between them; it is simply Ω_total = 1 restated, as both its proponents and earlier critics write it ([Haug & Tatum](https://www.scirp.net/pdf/jamp_1724348.pdf); [arXiv:1505.00812](https://arxiv.org/pdf/1505.00812)). Gaztañaga's black-hole-universe version is a different identity: it equates r_s with the de Sitter horizon c/(H₀√Ω_Λ), which is 1/√Ω_Λ ≈ 1.21 times larger ([ar5iv](https://ar5iv.labs.arxiv.org/html/2202.00641)). The engine reproduces it (5.614×10²² M☉ at Ω_Λ = 0.685) only when fed Ω_Λ, and its stored constant uses the Hubble version. The in-window r_s = R_H literature is low-tier: a non-peer-reviewed Zenodo preprint ([Exa record](https://exa.ai/library/publication/19x2p3pbgn4)) and a fringe "R_H = ct" paper ([PDF](https://constantecosmologique.fr/wp-content/uploads/2026/07/001-FHU-HTC-en.pdf)) whose Haug–Tatum CMB-temperature formula the engine reproduces at 2.7356 K. Reproducing a fringe formula does not validate it. The exact T_H = ½T_dS relation and the 2.27×10¹²² k_B horizon entropy are correct standard physics, but they inherit the same tautology.

**The new China Space Station test excludes long-range σ independently of MICROSCOPE.** In the repo's field reading, σ scales only the QCD share of hadron masses and nuclear binding, so different isotopes fall differently. Rerunning `scripts/unification/sigma_exclusion.py` against local Mentat reproduced the repo's own S9a exclusions exactly. Yb⁺/Cs clocks exclude long-range σ by ×3.23×10⁵ (ξ < 4.9×10⁻⁷), and MICROSCOPE by ×9.43×10¹⁰ (ξ < 1.68×10⁻¹²), or ×2.44×10¹¹ against its "no violation at 2.7×10⁻¹⁵" framing ([MICROSCOPE](https://arxiv.org/pdf/2209.15488)). The in-window ⁸⁵Rb/⁸⁷Rb atom-interferometer test aboard the China Space Station measured **η = (−2.7 ± 4.7)×10⁻⁷** ([Sci. Adv.](https://www.science.org/doi/10.1126/sciadv.aeh4502)). The engine's QCD fractions are 0.9858025 for ⁸⁵Rb and 0.9858637 for ⁸⁷Rb. Their difference predicts **η = 1.94×10⁻⁵ at orbital altitude, 16 times the 2σ bound of 1.21×10⁻⁶**, which caps the long-range coupling at ξ < 9.9×10⁻³ and excludes ξ = 0.158 for ranges λ ≳ 10³ km. That is far weaker than MICROSCOPE, but it is the first quantum-matter test in orbit, and on its own it rules out the field reading. ⁸⁷Rb is missing from `inventory/data/isotopes.json`, so its AME2020 mass had to be supplied by hand. The PTB bounds on α drift, (1/α)dα/dt = 1.8(2.5)×10⁻¹⁹ yr⁻¹ ([PTB-OAR](https://oar.ptb.de/resources/show/10.7795/110.20260227)), cannot touch this σ, because the code holds α fixed by construction (`sigma_ground/inventory/core/sigma.py:1-29`). Only μ- and Λ_QCD-sensitive probes can. What survives is a short-range corner: λ below about 34.5 km (MICROSCOPE), or the paper value m_σ ≈ Λ_QCD (λ = 0.909 fm). In the latter case σ at nuclear density is 6.5×10⁻⁴⁰, which is allowed precisely because no experiment can see it.

The cosmological-coupling premise fared no better. The peer-reviewed Lei et al. analysis of JWST AGN in red-sequence hosts found **k = −0.16 ± 0.39, rejecting k = 3 "black holes as dark energy" at 8.1σ** ([A&A](https://www.aanda.org/articles/aa/full_html/2026/10/aa61516-26/aa61516-26.html)). The caveat is that the test relies on JWST black-hole masses, which disagree with one another by two orders of magnitude. Any σ mechanism tying black-hole interiors to cosmic expansion now has to predict k ≈ 0. The holographic premise fails in its own way. With c² ≡ η and L = R_H, the engine under-predicts ρ_DE by 40%. The only way to rescue it is the trivial c² = Ω_Λ, and that cut-off class is excluded once CMB priors enter ([arXiv:2608.09379](https://arxiv.org/abs/2608.09379)). The repo's `eta_coincidence_report()` declares the coincidence "live" by comparing ETA with a constant defined to equal ETA (bug B8). Finally, the σ value at Earth's surface is internally inconsistent. `sigma_from_potential` gives 1.10×10⁻¹⁰, while 21 test files and the docstrings at `sigma_ground/inventory/core/sigma.py:294` and `sigma_ground/field/constants.py:453` use 7×10⁻¹⁰. Mentat's `gravitational_redshift` at Earth returns 6.954×10⁻¹⁰, which shows that 7×10⁻¹⁰ is the bare potential Φ/c² with ξ left out. The tests remain conservative, but the repo now carries three different Earth values.

One instrument could turn the surviving σ framework into a falsifiable claim. The ²²⁹Th isomer's 8.4 eV energy results from a near-cancellation of MeV-scale Coulomb and strong-force contributions. That enhances its sensitivity to α by **K = 5900(2300)** ([Nat. Commun.](https://www.nature.com/articles/s41467-025-64191-7)) and similarly amplifies any shift in Λ_QCD. The engine's own decomposition, BE(σ) = BE_strong·e^σ − BE_Coulomb, has the same structure. A Th-229 module would therefore probably be the most sensitive σ probe available. That is an inference, not a computation: ²²⁹Th is not in the isotope table, the engine has no isomer model, and the clock's d_g limits are published only as a figure.

## Conclusion

The engine does not fail by computing wrong physics. It fails by having nothing to compute with. Every gap the 41 checks found sits where 2026's physics moved: black-hole spin, the expansion history, dense-matter structure and nuclear-scale clocks. The contradictions that are not about σ, muon g−2 and α, trace to stale constants rather than wrong code, and the Planck-only H₀ is a plumbing choice. That means the most valuable work is additive. An H(z)/CPL module and a Kerr module would turn the largest share of this window's results (DESI's distances, the w₀w_a ages, GW250114's ringdown and area, the a₀(z) test) into permanent regression tests. The checks also show why Mentat's honesty rule matters in practice. Stale inputs produced a fake 5σ anomaly that the engine's own metadata called resolved, a hard-coded H₀ silently picked a side in a 7σ dispute, and a definitional identity looked like a cosmological coincidence until it was run at several values of H₀.

For the σ program, the 2026 data close the long-range reading from both a classical (MICROSCOPE) and a quantum-matter (China Space Station) direction. They leave only a short-range corner that is consistent with data because no current instrument can see it. The working ²²⁹Th nuclear clock is the first instrument whose physics, a near-cancellation of strong and Coulomb energies, matches the structure of the engine's own BE(σ) decomposition. A Th-229 sensitivity module is therefore the single build most likely either to give σ a falsifiable laboratory prediction or to finish excluding it. That choice, like every bug above, is for the user to make. Mentat's role is to report what the code does.
